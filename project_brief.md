# My agent: Travel & Adventure Concierge
One-liner: A conversational agent that helps travelers plan personalized trips with a catalog of destinations, interactive itinerary cards, and generated postcard visuals.

Tool coverage:
- Memory: Remembers traveler preferences (budget tier, dietary needs, preferred activity style, past visited cities)
- Tools: Real-time/simulated weather lookup, destination attraction search, itinerary generator
- Catalog/UI: Catalog of destinations, hotels, and daily activities rendered as rich cards and tables
- Image gen: Generates custom preview postcards / visual snapshots for destinations and key spots
- Sandbox: Computes total travel budget allocation, daily expense split, and currency conversion

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for budget math, live Maps API integration
